## Play declaration worksheet — do not submit without evidence

For every applicable category above, the owner/operator must verify and record:

- whether HappiNotes collects the data, whether it is optional, and the feature/purpose;
- whether data leaves the device, which vendors receive it, and whether it is shared for a vendor's independent purpose;
- whether data is encrypted in transit and whether users can request deletion;
- whether data remains after account deletion and the approved reason/period, where applicable;
- whether the answer changes by country, age group, platform, SDK or account state.

The source code does not prove production TLS, database encryption-at-rest, vendor retention, data regions, Firebase collection settings, store-console configuration or the final transitive SDK inventory. The current `blocked_policy` account-deletion gate means full account deletion is not implemented. Do not declare that all account data is deleted.
